# анимеДик

**[English version → README.md](README.md)**

Личный каталог аниме: своя полка, отметки просмотра, поиск по франшизам и
плеер, который помнит секунду, где вы остановились. Сервер — FastAPI и
SQLite, страницы — чистый JavaScript без фреймворков и без сборки.

> **Демонстрационный режим.** Доступа к чужому видео в этом репозитории нет
> и не будет. Вместо серий плеер крутит фильмы Blender Foundation под
> лицензией Creative Commons — этого хватает, чтобы показать, как работают
> поиск, плеер и отметки просмотра.

---

## Что это и зачем

Делал для себя. Хотелось, чтобы полка с аниме жила на моём железе, а не в
чужом сервисе, и чтобы плеер не терял место, где я остановился. Из этого
вырос сайт с аккаунтами, входом по коду, письмами о новых сериях и
небольшим ИИ-помощником.

Выкладываю как работу, на которую можно посмотреть. Честно о состоянии:
это **альфа**, эксперимент. Работает и закрыто своими наборами проверок, но
писалось под одного человека и один домашний сервер, а не как продукт.
И писалось вместе с ИИ (Claude) — в том числе чтобы понять, что такой
инструмент умеет на самом деле.

---

## Чего здесь нет

**Источников видео. Никаких.**

Личная версия берёт видео со сторонних сайтов. Здесь всё это убрано:
список источников, их разборщики, порядок перебора и библиотеки.
Выкладывать такое незаконно, и проблем я не хочу.

Место, куда подключается источник, описано: в `api/anime.py` пустой
словарь `SOURCES` и объяснение четырёх методов, которые должен уметь
модуль источника (`api/anime_demo.py` — рабочий образец). Кто подключит
свой источник — делает это сам и сам за это отвечает.

С `MODE=private` и без подключённого источника все ручки видео честно
отвечают **501**, остальное работает.

## Что умеет

- **Поиск по франшизам.** На «наруто» приходит одна карточка «Наруто», а не
  двадцать строк вперемешку. Внутри — все части истории по годам, с
  отметкой той, с которой начинают. Данные — из открытых справочников
  (Shikimori, AniList, Jikan), без ключей и регистрации.
- **Одно аниме — одна карточка.** Четыре сезона и два фильма — всё равно
  одна карточка на полке, с полосой прогресса и «серия N из M».
- **Плеер.** HLS и обычные файлы, перематываемая полоса, полный экран,
  переход между сериями и частями прямо из плеера, субтитры (SRT/ASS/VTT
  сервер переводит в WebVTT). Секунда сохраняется, даже если закрыть
  страницу.
- **Два языка, и они раздельные.** Язык сайта (русский/английский) и язык
  аниме (озвучка или субтитры) — две разные настройки.
- **Аккаунты без регистрации.** Аккаунты заводит хозяин из консоли или из
  админки. Роли: гость, пользователь, админ. Вход по коду из приложения
  (TOTP, написан здесь без зависимостей), запасные коды, «выйти везде».
  По желанию — общий **демо-аккаунт** для витрины: вход одной кнопкой,
  посмотреть можно всё, поменять — ничего.
- **18+ скрыто по умолчанию**, включается в профиле; отдельный
  переключатель «Хентай» — только для вошедших, гостям никогда.
- **ИИ-помощник** (пузырь «?») — только для вошедших: отвечает про сайт и
  коротко про аниме, не знает названия и адреса сайта, не ходит в интернет
  и ничего не делает на сайте. Необязателен — без ключа выключен.
- **Итоги года**, темы, праздничное оформление (Новый год, Хэллоуин,
  Сакура), которое включается само по дате, колокольчик новых серий и, по
  желанию, письма о них.

## Быстрый запуск

С Docker:

```bash
cp .env.example .env
# в SESSION_PEPPER — длинную случайную строку (openssl rand -hex 32),
# COOKIE_SECURE=0 — если открываете сайт по обычному http://localhost
docker compose up -d --build
docker compose exec app python -m api.admin add ваш_логин --admin
```

Откройте `http://localhost:8080`.

Без Docker, на Linux и Windows — подробно в **[INSTALL.md](INSTALL.md)**
(документы — на английском).

## Что где лежит

```
api/
  main.py          веб-приложение: страницы и ручки API
  anime.py         связь с источниками видео — сюда подключается ваш
  anime_demo.py    демонстрационный источник: свободные фильмы Blender
  catalog.py       справочник: поиск, описания, жанры, франшизы
  store.py         SQLite: аккаунты, полка, отметки, сессии
  security.py      пароли, сессии, метки форм, ограничения частоты
  twofa.py, qr.py  вход по коду из приложения и его QR-код
  hls.py           прокладка для видео, которому нужен Referer
  subtitles.py     субтитры любого вида → WebVTT
  netguard.py      исходящие запросы — только в открытый интернет
  helper.py        ИИ-помощник
  mail.py          письма о новых сериях
  errors.py        тексты ошибок на двух языках
  admin.py         управление аккаунтами из консоли
web/               страницы, стили и скрипты — без сборки и фреймворков
deploy/            настройки nginx
tests.py, check*.py   наборы проверок
```

## Стек

Python 3.12, FastAPI, SQLite (WAL), чистый JavaScript (ES5), hls.js,
Docker Compose, nginx, Cloudflare Tunnel.

Зависимости: FastAPI, uvicorn, httpx, Pillow (точные версии — в
`api/requirements.txt` и `api/constraints.txt`). Вход по коду, QR-коды и
перевод субтитров написаны здесь — незачем тянуть библиотеку ради
нескольких десятков строк, которые потом надо обновлять.

Комментарии в коде и вывод проверок — на русском.
