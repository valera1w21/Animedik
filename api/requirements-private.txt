# Зависимости личной версии — то, чего нет в публичной.
#
# Ставятся поверх requirements.txt и нужны только при MODE=private,
# когда сайт берёт видео с внешних источников, которые вы подключили сами
# (см. api/anime.py, SOURCES).
#
# Docker ставит этот файл сам (см. Dockerfile), отдельным шагом после
# requirements.txt. Без Docker, у себя на компьютере:
#
#     pip install -r api/requirements.txt -r api/requirements-private.txt -c api/constraints.txt
#
# В публичной версии здесь только комментарии: источников нет, ставить
# нечего. Файл, в котором одни комментарии, Docker-сборку не ломает — шаг
# установки просто пропускается.
#
# Подключаете источник на сторонней библиотеке — впишите её сюда с точной
# версией (==), пересоберите api/constraints.txt (как — в его заголовке) и
# добавьте имя модуля в anime.LIBRARIES: тогда сервер без неё честно
# скажет «не установлена библиотека», а не «источник молчит».
